The supplied nginx/Python demo validates Front Door -> Application Gateway -> web VMSS -> internal Load Balancer -> app VMSS. It intentionally reports database_connected=false: SQL is provisioned separately, but this demo does not run SQL queries. Validate SQL using an Entra administrator from an application VM or a dedicated private management VM, then add your application and managed identity database permissions. The GIF's HA database icons represent Azure-managed replicas, not Terraform-created VMs. NAT is associated with the regional web/app subnets; it does not make a subnet public. Standard NAT here is non-zonal; the image's per-zone NAT positions are logical, not a guarantee of zone-resilient egress. For a production egress design choose a region-supported zone-redundant SKU and validate provider support.
